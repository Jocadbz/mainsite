Navi

See Repo

Description

navi is a terminal-based coding agent written in Rust. It works with local or remote OpenAI-compatible models, or with a ChatGPT plan through Sign in with ChatGPT. It can inspect projects, make edits, and run commands with configurable permissions.

Build

Requires Rust 1.88 or newer, a C toolchain, and /bin/sh. Linux is the primary platform; macOS is also supported. Windows is not currently supported.

cargo build --release --locked

The compiled binary is at target/release/navi. To install it with Cargo:

cargo install --path . --locked
